Download the Cerberus beta

Read this before you download. This is a beta test version of Cerberus, version 1.0, for Android. It is not the finished app.

  • It can have bugs and you could lose data. Do not make it the only place your passwords live. Keep your real passwords in another manager until you trust it.
  • Pro features are shown but locked. Tapping one opens a screen explaining that you carry the beta and that the full app with Pro is coming to the Google Play Store soon. The beta has no purchase and no test switch.
  • Pictures attached to items are never included in backups (or sync, which is a Pro feature). That is by design.
  • It is not independently audited. See Security.
  • The first time you open it, a notice repeats these points.

Get the APK

The beta is published as a release in its own GitHub repository:

Open the Cerberus_beta releases page

Download the zip file (it contains Cerberus_BETA_1.0.apk) and SHA256SUMS.txt from the newest release, then unzip the file to get the APK. The file is not on Google Play and is not offered anywhere else.

Check the file before you install

  1. Unzip the download, then compare the SHA-256 of the APK inside it (not of the zip) with the value in SHA256SUMS.txt on the release page. On Android you can use a hash-checking app; on a computer run sha256sum Cerberus_BETA_1.0.apk or, on Windows, certutil -hashfile Cerberus_BETA_1.0.apk SHA256.
  2. The two must match exactly. If they do not, delete the file and do not install it.

SHA-256 of Cerberus_BETA_1.0.apk: 6520a967b6779c9f64d72935277aab4598a3dbc52b7457fa884db2ee97935892

Signing certificate SHA-256 (beta): 35:AA:A9:DA:A8:26:19:ED:A7:41:1A:3A:FF:68:85:94:86:7D:20:D4:17:BA:81:F2:3F:DA:71:00:6B:D9:1A:CB

Check it with apksigner verify --print-certs Cerberus_BETA_1.0.apk. The beta uses its own signing key, so this differs from the fingerprint on the Security page, which is for the main app. If the value does not match, do not install it.

Install

  1. Open the downloaded APK on your phone.
  2. Android will ask you to allow installs from this source (your browser or file manager). Allow it for this install, then turn it off again afterwards.
  3. If Play Protect warns about an app it has not seen before, that is expected for a file outside the Play Store. Choose to install anyway only if the hash matched.
  4. Open Cerberus, read the beta notice, and set up your master password, recovery phrase and recovery image. Test the recovery image from Settings, Account security.

Requires Android 8.0 or newer.

Updating and removing

Beta updates are new releases on the same page. Install the new APK over the old one only after checking its hash. Uninstalling the app deletes the vault on that phone, so make an encrypted backup first.
